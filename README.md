## 这是什么

零依赖的 Node.js 本地服务 + 原生网页前端，数据存在本机文件里：

- 大纲树（卷 / 组 / 章节）
- 角色卡、情节线、世界树、物品
- 书架：一本书一个目录，正文是 `data/books/<书id>/text/<id>.md`，纯文本，记事本就能打开
- 断网、断电、手快关窗口都不丢字
- 手机连同一个 WiFi 就能写，两台设备实时同步

## 下载

不想装环境的话，直接用这两个：

| 文件 | 给谁 | 说明 |
| --- | --- | --- |
| [`Setup.exe`](Setup.exe) | Windows 10 / 11 | 双击就装。**自带 Node 运行时**，电脑上没装过 Node 也能跑 |
| [`茉写作.apk`](茉写作.apk) | 安卓手机 | 装了电脑版之后，手机连同一个 WiFi，就能通过它连到电脑上的写作台 |

两个文件都不含任何作品内容，装完之后库是空的，第一件事是新建一本书。

> 装电脑版之后，在「设置」面板里也能直接下这两个文件，不用回来看仓库。

## 开始用

双击 `Setup.exe`，选一个目录，装完桌面会出现「茉写作」图标，点开就能写。

- 第一次打开会让你设密码；忘了密码就删掉安装目录下的 `密码.txt` 和 `config.json`，重启会重新生成。
- 手机连同一个 WiFi，打开「设置 → 手机 / 平板」里那个地址就能写。
- 稿子都在安装目录的 `data` 文件夹里，纯文本，随时能备份或搬走。

## 环境

- Windows 10 / 11
- Node.js 18+（不需要 `npm install`，本项目零第三方依赖）

```bash
node server.js
# 打开 http://127.0.0.1:7788
```

首次启动会生成 `config.json` 和 `密码.txt`，默认密码 `12345678`。

## 目录

```
server.js              服务端（单文件，零依赖）
zipper.js              「打包带走」用的 ZIP 写入器（同样零依赖）
public/                前端：index.html + app.js/core.js/view-*.js + style.css
run-loop.bat           带守护的启动脚本（进程挂了自动拉起）
autostart.vbs          静默拉起 run-loop.bat（开机自启用）
Setup.exe              电脑版安装包（自带 Node，35 MB）
茉写作.apk             安卓壳，连同一台电脑上的服务
data/                  写作数据（首次启动自动生成，不进版本库）
```
